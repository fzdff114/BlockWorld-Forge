# BlockWorld-Forge — Procedural World & Structure Generator

Android 原生 Minecraft Bedrock 世界生成器。**不依赖地图服务、不下载真实高程、不采集外部建筑数据**，直接用本地种子算法构建地形和结构。无需 Google Play 服务。

当前版本：**0.7.0（预发布）**

## 0.7.0 — 自定义世界尺寸与地质层

- **程序地形**：多尺度噪声组合大陆、山脉、尖峭山脊、平原和高原；可调高度起伏、崎岖度、高原比例和水位。0.7.0 默认世界扩大到 1536×1536，并支持手动输入 128–2048 的边长。
- **29 种 Bedrock 群系定义**：包括平原、森林、白桦林、黑森林、针叶林、巨型针叶林、沙漠、恶地、热带草原、丛林、竹林、沼泽、红树林、蘑菇岛、樱花林、草甸、雪地、冰刺、三类山峰、三类海洋、繁花森林、苍白花园等。
- **洞穴与矿脉**：程序化 3D 洞穴通道/空腔；煤、铁、铜、金、红石、青金石、钻石、绿宝石，并在负高度生成深板岩矿石变种。
- **地下岩层**：按种子生成深板岩、凝灰岩、方解石、花岗岩、闪长岩和安山岩矿带，不再让地下大部分区域都是单一石头。
- **多种树木造型**：橡树、白桦、云杉、巨型云杉、丛林树、金合欢、深色橡木、红树、樱花树、苍白橡木和蘑菇树；树干、横向树枝、树根使用对应轴向状态与原版方块。
- **8 类结构/遗迹**：村庄群落、沙漠神殿、丛林神庙、破损传送门、地下矿道、地下要塞、海底遗迹、山地瞭望塔。采用原版风格方块重新构建，并非直接复制游戏内原版结构模板。
- **文件体积控制**：边长可手动输入 128–2048 方块，默认 1536；显示估算压缩体积和导出的真实大小、实际区块数量。
- **Bedrock 区块格式**：写入 3D 群系调色板、地形高度图、方块调色板和 SubChunk v9；区块分批写入 LevelDB，生成后关闭并重开校验。
- **地图流程退出主界面**：主页面现在只有生成器、项目和导出，不再要求圈选地图或等待地图数据。

## 使用方法

1. 打开“生成器”，输入世界名称和随机种子。
2. 选择世界边长、细节档位、高度起伏、山脉崎岖度、高原比例和水位。
3. 选择群系数量（20–29），调整树木密度、洞穴密度、矿脉丰富度和结构密度。
4. 开关洞穴、矿石、树木、海洋湖泊和结构，选择需要出现的遗迹类型。
5. 查看地形预览与 .mcworld 体积估算，点击“保存世界生成方案”。
6. 到“项目”确认方案，再到“导出”生成 .mcworld 并用 Minecraft Bedrock 打开。

## 下载慢时的备用入口

- 优先使用 GitHub 官方 Release 直链。
- 若 GitHub 直连很慢，可尝试 GHFast 或 GH-Proxy 第三方代理；代理节点的速度和可用性可能变化。
- 通过代理下载后，使用 Release 提供的 SHA-256 文件校验 APK；不要安装校验不一致的文件。

## 世界与文件大小

- 世界边长是方块数，不是地图公里数；默认 1536 表示 1536 × 1536 方块，面积是 1024 方块世界的 2.25 倍。
- 低体积档降低高频地形细节；标准档是默认平衡；高细节档增加地表噪声细节，并提高体积估算。
- 更大的世界有更多区块，生成时间和文件大小都会上升。2048 × 2048 有 16,384 个区块，建议先用 1024 或 1536 测试，再尝试 2048。
- 体积显示是估算值，不是文件大小保证；LevelDB 压缩、洞穴空腔、树木和结构分布会影响实际输出。
- 当前为完整预生成方块世界，不是无限实时地形生成。为兼顾手机性能，单边限制在 2048 方块；更大的世界会显著增加运算时间、存储与内存压力。

## 结构说明与限制

- 结构是本项目自建的原版风格变体，使用 Bedrock 方块调色板写入，不是复制 Mojang 原版结构文件或模板。
- 地形、群系、洞穴、矿石、树木和结构使用同一个种子；相同设置和种子会得到可重复布局。
- 群系分配以程序气候噪声和地形高度为依据；当前不是完整复刻原版生物群系生成算法。
- 目前不生成生物、村民、战利品箱内容、红石机关或完整结构实体；结构以方块形式呈现。
- 地形预览是高度场缩略图；最终方块外观以 Minecraft Bedrock 实机导入结果为准。
- 0.7.0 增加了自定义尺寸、地质岩层和区块规模回归测试；仍需在目标手机和实际 Minecraft 版本进行导入验收。

## 构建

需要 JDK 17、Android SDK 35 与 Gradle 8.14.3。运行：gradle --no-daemon testDebugUnitTest 和 gradle --no-daemon assembleDebug。
