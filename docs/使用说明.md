# 方块世界工坊 0.1.1 使用说明

## 1. 应用定位

本版本是 Android 原生界面预览版，目标是逐步实现：选择地图区域和地理数据 → 生成地形与群系 → 放置遗迹和探索内容 → 导出 Minecraft 基岩版世界。

当前版本尚未接入真实地图解析和地形生成引擎，因此不能把本版本当作完整地图制作器使用。

## 2. 页面说明

### 工作台
展示示例世界项目、开发模块状态，并通过“新建世界项目”创建一条临时草稿。示例项目和新建草稿当前保存在应用运行期间的内存中，关闭应用后不会保证保留。

### 地图
点击“选择地图文件”会打开 Android 系统文件选择器。选中文件后应用只显示文件名，不读取地图内容、不上传文件，也不会生成地形。页面列出的格式是未来计划支持的输入格式，不代表已经完成解析。

### 世界生成
可以调整世界尺寸（4K、6K、10K、15K、20K）、地形风格，以及高程、水系、结构遗迹开关。当前这些选项只用于界面预览和配置交互，不会执行真实生成。

### 资源库
展示未来计划支持的群系预设、结构遗迹和地表材质规则。当前为规划展示页面，尚不能新增、编辑或导入资源。

### 导出
展示未来的基岩版世界导出步骤。当前点击导出只会提示导出功能尚未实现，不会创建 .mcworld 文件。

## 3. 安装方式

从 GitHub Actions 下载最新的 `BlockWorld-Forge-Android-debug` 构建产物，解压 ZIP 后安装其中的 `app-debug.apk`。本项目目前提供 Debug 测试包，不是商店发布包。

## 4. 隐私与文件权限

目前没有地图上传服务，也没有把所选文件发送到网络的逻辑。文件选择由 Android 系统文件选择器负责；当前应用只读取所选文件的显示名称。地图内容解析和外部数据服务尚未接入。

## 5. 已知限制

- 项目草稿和页面配置尚未持久化。
- 不支持地图预览、地图解析或坐标选区。
- 不支持真正的地形、群系、河流、遗迹和区块生成。
- 不支持生成或导出 .mcworld。
- 当前功能状态不等同于未来版本承诺，后续以实际提交和测试结果为准。
