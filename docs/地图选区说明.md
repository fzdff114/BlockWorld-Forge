# Atlas 0.3.0 地图转世界

1. 在“地图”页圈选区域。
2. 点击“采集高程”。
3. 点击“存为项目”并选择比例。
4. 打开“导出”，点击项目右侧“生成世界”。
5. 在系统文件保存器中保存 mcworld，然后用 Minecraft 基岩版打开。

## 比例

比例按水平距离换算：1:1 表示 1 个 Minecraft 方块对应 1 米；1:4 表示 1 个方块对应 4 米，以此类推。

当前垂直高程会自动适配到基岩版高度范围，避免高山超过世界上限。若选区过大，增加比例尺以减小生成方块数。

## 当前转换内容

生成基岩、石头、泥土、草地；海平面以下区域使用沙底和水层。高程网格为 20×20，插值会平滑采样点之间的坡面，但不会增加数据源没有的山脊或山谷细节。

当前限制：最大边长 512 方块，总计最多 262,144 个地表格。道路、建筑、森林、真实河网、洞穴、群系和遗迹尚未生成。
