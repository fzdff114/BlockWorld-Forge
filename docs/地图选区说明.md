# Atlas 0.2.0 地图选区

1. 进入底部“地图”。
2. 地图默认显示中国区域的地形底图，可通过双指缩放、拖动浏览其他地区。
3. 也可在顶部输入“纬度, 经度”，点击“定位”跳转。
4. 点击地图添加选区顶点。按顺序沿目标区域边缘点击，至少 3 个点闭合形成多边形。
5. “撤销”删除最后一个点；“清空”重新圈选。
6. 点击“采集高程”读取所选范围的现实地形高程。完成后会显示海拔范围、平均值和网格预览。
7. 点击“存为项目”将区域边界和高程网格放入项目草稿。

## 数据来源

- 地形底图：OpenTopoMap（地图数据 © OpenStreetMap contributors、SRTM；样式 © OpenTopoMap，CC-BY-SA）。
- 高程：Copernicus DEM GLO-90，通过 Open-Meteo Elevation API 获取，数据约 90 米分辨率；每次请求最多 100 个坐标。
- 请求仅包含地图瓦片坐标或选中区域的地理坐标，不上传用户选择的本地地图文件。
