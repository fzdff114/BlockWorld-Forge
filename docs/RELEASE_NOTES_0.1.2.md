# Atlas 0.1.2

**版本类型：** Android 测试版  
**应用 ID：** `com.fzdff.blockworldforge`  
**版本号：** `0.1.2 (3)`

## 更新内容

- 应用名称调整为 Atlas。
- 更换为简洁的几何图标。
- 采用更精简的原生手机工具布局。
- 页面收敛为项目、地图、地形、素材、导出。
- 移除宣传横幅、重复介绍和多余说明。
- 保留中文操作界面与白色、蓝色视觉风格。

## 当前限制

此版本仍是界面原型。地图文件解析、地形生成、项目本地持久化、素材编辑和基岩版 `.mcworld` 导出尚未实现。

## 安装要求

- Android 7.0 或更高版本（API 24）
- 不依赖 Google Play 服务
- 当前发布包为 Debug 构建，用于设备测试
